[01] 다운로드 폴더 정리
※ ★ 필수 하나만 하면 돼요. 아래 '더 해보기'는 시간 남을 때 골라서.
준비: 새 에이전트 → 입력창 + → 폴더 첨부하기 → '다운로드_흉내' (파일은 안 열어도 됨)

② ★ 필수
아래 규칙대로 하위 폴더를 만들어서 정리해 줘.
- 파일 이름에 '본문', '첨부', '붙임'이 있는 공문 → 01_공문
- 계획서, 보고서 → 02_계획보고
- 엑셀, csv(명렬표·예산·설문) → 03_명렬표예산
- 사진, 캡처 → 04_사진
- 무슨 파일인지 모르겠는 것(asdf, 제목없음, 새 압축 파일, exe 등) → 99_확인필요
옮기기 전에 '원래 이름 → 옮길 폴더' 표를 먼저 보여 주고, 내가 좋다고 하면 그때 옮겨 줘.


[더 해보기(선택): 시간 남으면]

①
이 폴더에 뭐가 있는지 한글, PDF, 엑셀, 사진, 기타로 나눠서 개수만 세어 줘. 아직 아무것도 옮기지 마.

③
'최종', '진짜최종', '(1)', 'v2', 'v3'처럼 같은 문서가 여러 개 있는 것을 찾아서 묶어 보여 주고, 어느 게 최신인지 추측만 해 줘. 지우지는 마.

④ (보너스: 내 진짜 다운로드 폴더)
내 다운로드 폴더에서 2주 넘게 안 쓴 파일을 종류별로 목록만 보여 줘. 옮기거나 지우지는 마.

[추가 실습: 실제 안전 업무 문서]
'다운로드_흉내' 폴더에 실제 학교 안전 업무 인수인계 폴더의 파일 이름을 본뜬 파일 25개가 더 들어 있어요. (학교 이름만 오현초로 바꿨고, 내용은 0바이트 빈 파일)

⑤
이름에 '오현초등학교-번호'가 들어간 공문 파일을 같은 번호끼리 묶어서 '번호 | 본문 | 첨부 | 짝 상태' 표로 보여 줘. 본문만 있거나 첨부만 있는 번호도 따로 알려 줘. 아직 옮기지 마.

⑥
안전 업무 파일을 업무별(학교안전계획 / 안전교육 / 소방·대피훈련 / 수상안전 / 기타)로 나누고, 그 안에서 연도별로 하위 폴더를 만들어 정리하는 계획을 표로 보여 줘.
- 이름 앞의 '[오현초등학교-1907 (본문)]' 같은 머리말은 떼고 '2024_학교안전관리종합계획_본문.odt'처럼 '연도_문서이름_본문/첨부' 규칙으로 바꾸기
- 연도가 이름에 없는 파일(예: 5월 안전 예보)은 [확인 필요]로 표시
- 내가 좋다고 하면 그때 옮기고 이름을 바꿔 줘

[추가 실습: 사진 정리 → 통합 사진 → 뮤직비디오 배경 영상]
준비: '다운로드_흉내' 폴더 안의 사진 22장 (IMG_4471.jpg, 다운로드 (7).png, 제목 없음.png 처럼 이름만 봐선 뭔지 모르는 사진들)

⑤ 
이 폴더의 사진(jpg, png)을 하나씩 열어 보고, 무엇이 찍혔는지 보고 새 이름을 지어 줘.
이름 형식은 '주제_내용' (예: 꿀벌캐릭터_환영, 분리수거_캔_01)로 하고,
'원래 이름 → 새 이름 → 옮길 폴더' 표를 먼저 보여 줘. 아직 바꾸지 마.

⑥ 
좋아, 표대로 이름을 바꾸고 '04_사진' 아래 주제별 폴더(꿀벌캐릭터, 나라랜드마크, 분리수거, 배경무늬)로 옮겨 줘.
열리지 않는 사진(0바이트)은 99_확인필요로.

⑦ 
꿀벌캐릭터 사진 8장을 한 장의 통합 사진으로 만들어 줘.
2줄 × 4칸 격자, 칸 사이 여백 조금, 배경은 연한 노란색. '꿀벌_모음.png'로 저장해 줘.

⑧ 
꿀벌캐릭터 사진 8장을 순서대로 이어 붙여 뮤직비디오 배경 영상을 만들어 줘.
- 16:9 가로 화면, 한 장에 2초, 장면이 부드럽게 넘어가게
- 음악은 나중에 넣을 거라 소리는 비워 두기
- '꿀벌_뮤비_배경.mp4'로 저장
(※ 영상 만들기는 inline AI에서 안 될 수도 있어요 [리허설 확인]. 안 되면 마지막 시간의 클로드 코워크로 해 보세요.)
