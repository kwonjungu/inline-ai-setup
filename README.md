# inline AI 업무 실습 연수 (초등)

> 일단 던지고, 내 컴퓨터에 초대하고, 정해진 양식을 주세요.

초등 선생님이 실제 학교 문서로 inline AI를 써 보는 연수 자료입니다.
마지막에는 같은 일을 **클로드 코워크**로 하는 방법까지 소개합니다.

## inline AI 설치

- 내려받기: https://inline-ai.com (Windows)
- 초대 이벤트(무료 1,000 크레딧): https://portal.inline-ai.com/invitation-promotion?code=K2YERY3H · 초대 코드 `K2YERY3H`

## 실습 자료 받기

**[inlineAI_실습.zip 내려받기](https://github.com/kwonjungu/inline-ai-setup/raw/main/download/inlineAI_실습.zip)** → 바탕화면에 압축 풀기 → inline AI의 '접근 가능한 폴더'에 `inlineAI_실습` 추가

## 실습 순서

| # | 실습 | 폴더 |
|---|---|---|
| 0 | README(하네스) — 먼저 읽기 | `materials/00_README(하네스).txt` |
| 1 | 다운로드 폴더 정리 | `materials/01_다운로드정리` |
| 2 | 학교 가정통신문 양식 맞추기 | `materials/02_가정통신문_양식맞추기` |
| 3 | 한글 표 만들기 | `materials/03_한글표만들기` |
| 4 | 작년도 문서 업데이트 | `materials/04_작년도문서_업데이트` |
| 5 | 행정 처리 도움받기 | `materials/05_행정처리_도움받기` |
| 6 | 계획서로 기안문 쓰기 | `materials/06_계획서로_기안문쓰기` |
| 7 | 계획서로 보고서 쓰기 | `materials/07_계획서로_보고서쓰기` |
| 8 | 계획서·통계로 PPT 만들기 | `materials/08_계획서_통계로_PPT만들기` |
| 9 | 마무리: 클로드 코워크와 앱 설치 | (준비 중) |

프롬프트는 [프롬프트 모음](https://inline-ai-setup.vercel.app/prompts.html)에서 [복사] 버튼으로 씁니다. (오프라인 예비본: `materials/00_프롬프트_전체.txt`, 원본: `prompts/`)

## 개인정보
실습 자료 속 사람 이름은 실습용 가상 이름(실존 인물 아님), 학교는 **오현초등학교**입니다.
오현초 실제 문서는 이름·연락처·링크를 지운 익명화본입니다.

## 강의안
- [강의안 보기(lecture.html)](lecture.html) — 연수 번호 입력 후 열림. ← → 넘기기 · N 발표자 노트 · T 목차 · F 목록/발표 · P 인쇄 보기 · 오른쪽 위 한국어/English/Tiếng Việt
- PDF: `deck/강의안.pdf` (열기 암호 = 연수 번호) · 원고 장 대응표: [deck/강의안_대응표.md](deck/강의안_대응표.md)
- 메모: 강의안의 연수 번호(1111)는 브라우저에서만 확인하는 잠금이라 소스를 보면 보입니다. 지나가는 접근만 막는 용도이고, 민감한 내용은 강의안에 넣지 않습니다.
