# 강의 원칙 (모든 에이전트 공통)

이 강의는 "AI에게 일 시키는 법"을 배우는 연수가 아니라, **내 업무 파일을 AI에게 맡겨 보는 연수**입니다.

## 쉬운 말 세 가지

1. **일단 던지세요.**
   잘 쓴 프롬프트를 고민하기 전에 한 줄이라도 먼저 시켜 봅니다. 결과를 보고 고치는 게 더 빠릅니다.
2. **내 컴퓨터에 초대하세요.**
   복사·붙여넣기가 아니라, 파일과 폴더를 열어 두고 AI를 그 자리에 부릅니다.
3. **정해진 양식을 주세요.**
   "알아서 예쁘게"보다 "우리 학교 양식 그대로"가 훨씬 정확합니다.

그리고 하나 더:
> **긴 설명보다 자료 하나가 더 강력한 예시다.**
> 슬라이드에 설명을 길게 쓰지 말고, 실제 파일·화면·결과물 한 장을 보여 준다.

## 슬라이드 글자 수 (강의안 규칙 — 10/5 완화: 증빙 자료)
강의안은 연수 **증빙 자료**로도 쓰이므로, 슬라이드만 보고도 무엇을 했는지 알 수 있게 씁니다.

| 요소 | 기준 |
|---|---|
| 제목 | 1~2줄, 줄당 20자 안팎 |
| 설명 | 2~3줄, 한 줄 40자 안팎 |
| 카드·알약 | 3~4개, 각 20자 안팎 |
| 프롬프트 장 | 프롬프트 원문을 상자에 그대로 (길이 제한 없음, 글자 크기로 조절) |
| 한 장 전체 | **100자 안팎, 최대 140자** (프롬프트 원문·꼬리말 제외) |

- 그래도 '한 장 = 한 메시지'. 강사가 할 말 전부는 발표자 노트에
- 캡처 화면은 제목 한 줄 + 설명 한 줄 + 빨간 네모 강조

## 쓰기 규칙
- 초등 담임 눈높이. 전문용어(RAG, 에이전트, 컨텍스트 등)는 쓰지 않거나 한 번만 쉬운 말로 풀기
- 한 슬라이드 = 한 메시지, 글은 3줄 이내
- "~해요/~합니다" 대화체, 짧게
- 모든 실습은 `파일 열기 → 한 줄로 시키기 → 확인 → 필요한 부분만 다시` 순서
- 개인정보: 실습 자료의 사람 이름은 실습용 가상 이름(실존 인물 아님), 학교는 **오현초등학교**
  - 역할별 이름: 학교장 윤서진 / 디지털교육부(정보부) 담당 한지우 / 과학진로부 동아리 담당 오태민 / 수상안전 담당 강민서 / 전세버스 업체 대표 류건우 / 교구사 대표 탁현수 / 08 공문 결재자 문가은·배서윤·남도현 / 03 4반 학생 26명은 정답지 03 절
- 확인되지 않은 사실(요금·기능·버전)은 [확인 필요]로 남기고 지어내지 않기
