# 강의 원칙 (모든 에이전트 공통)

이 강의는 "AI에게 일 시키는 법"을 배우는 연수가 아니라, **내 업무 파일을 AI에게 맡겨 보는 연수**입니다.

## 쉬운 말 세 가지

1. **일단 던지세요.**
   잘 쓴 프롬프트를 고민하기 전에 한 줄이라도 먼저 시켜 봅니다. 결과를 보고 고치는 게 더 빠릅니다.
2. **내 컴퓨터에 초대하세요.**
   복사·붙여넣기가 아니라, 파일과 폴더를 열어 두고 AI를 그 자리에 부릅니다.
3. **정해진 양식을 주세요.**
   "알아서 예쁘게"보다 "우리 학교 양식 그대로"가 훨씬 정확합니다.

그리고 하나 더:
> **긴 설명보다 자료 하나가 더 강력한 예시다.**
> 슬라이드에 설명을 길게 쓰지 말고, 실제 파일·화면·결과물 한 장을 보여 준다.

## 쓰기 규칙
- 초등 담임 눈높이. 전문용어(RAG, 에이전트, 컨텍스트 등)는 쓰지 않거나 한 번만 쉬운 말로 풀기
- 한 슬라이드 = 한 메시지, 글은 3줄 이내
- "~해요/~합니다" 대화체, 짧게
- 모든 실습은 `파일 열기 → 한 줄로 시키기 → 확인 → 필요한 부분만 다시` 순서
- 개인정보: 실습 자료의 사람 이름은 모두 **홍길동**, 학교는 **오현초등학교**
- 확인되지 않은 사실(요금·기능·버전)은 [확인 필요]로 남기고 지어내지 않기
