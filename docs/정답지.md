### 체험학습_예산표.xlsx
**① 단가×수량 ≠ 금액 (오류 2곳)**
| 품목 | 단가×수량 | 적힌 금액 | 차이 |
|---|---|---|---|
| 여행자보험 | 1,200 × 98 = **117,600** | 116,000 | **1,600원 적게** 적힘 |
| 물티슈 | 800 × 100 = **80,000** | 8,000 | **72,000원 적게** 적힘 (0 하나 빠짐) |
- 나머지(전세버스 900,000 / 간식 1,500×105=157,500 / 구급약품 50,000 / 예비 재료 50,000)는 맞음
- 원래 합계 1,281,500 → **정정 합계 1,355,100원** (총예산 1,200,000 대비 **155,100원 초과**)

**② 조건 안에서 맞추기 → 불가능이 정답**
- 고정: 버스 900,000 + 보험 117,600 + 구급약품 50,000 = 1,067,600 → 남는 돈 132,400
- 간식 최소: 학생 98명 × 1,500 = 147,000 (인솔교사 6명까지 넣으면 104개 = 156,000)
- 물티슈·예비 재료를 **0으로 해도** 1,067,600 + 147,000 = 1,214,600 → **최소 14,600원 부족**
  (간식을 교사 포함 104개로 보면 1,223,600 → 23,600원 부족)
- 물티슈·예비 재료를 그대로 두면 부족액은 155,100원 − (간식 105→98개 줄임 10,500) = **144,600원**
- 확인 포인트: AI가 보험 수량을 줄이거나 간식을 98개 아래로 내려 "억지로 맞추지" 않는지

**③ 산출 내역 예** — `여행자보험: 1,200원 × 98명 = 117,600원`, `물티슈: 800원 × 100개 = 80,000원` (정정값으로 써야 함)
