## 1. 설치 3단계

**1-1. 내려받기** — `claude.ai/download` 에서 **Windows용 다운로드** 를 눌러요.
![](../assets/shot/claude/01_download_page_1280.png)
- 주의: 일반 PC는 'Windows용 다운로드', ARM 노트북(서피스 등)만 'Windows(arm64)'. Microsoft Store로도 받을 수 있어요.

**1-2. 설치 후 첫 화면** — 설치 파일을 실행하면 "Claude for Windows — Claude와 대화하는 가장 빠른 방법" 화면이 떠요. **시작하기** 를 눌러요.
![](../assets/shot/claude/02_welcome_1280.png)

**1-3. 로그인** — **Google로 계속하기** 또는 이메일 입력 → **이메일로 계속하기**.
![](../assets/shot/claude/03_login_1280.png)
- 주의: 코워크를 쓰려면 이 계정이 **Pro 이상 유료 요금제**여야 해요. 무료 계정은 채팅만 돼요.

> 앱 왼쪽 위 ≡ 메뉴(로그인 전에도 보임): 파일 · 편집 · 보기 · 이동 · 도움말
> - 보기: 명령 팔레트…(Ctrl+K) · 패널 닫기(Ctrl+\) · 분할 보기 · 실제 크기 · 확대 · 축소 · 새로고침(F5)

## 3. 공문서 하네스를 스킬로 올리기

1. `materials/00_하네스_공문서/클로드_스킬용` 폴더를 확인해요. 안에 `SKILL.md` 와 `references/`(03~07 파일)가 있어요.
2. 폴더를 **zip으로 압축**해요. 업로드 화면 조건: ".zip 또는 .skill 파일에는 SKILL.md 파일이 포함되어야 합니다".
3. 클로드 앱 **사용자 지정 → 스킬 → + 추가 → 스킬 업로드** (2-11~2-13 화면)
4. zip을 끌어다 놓고 **업로드**. 업로드하면 보안 검사가 실행돼요.
5. **내 항목** 목록에 `school-official-docs` 가 보이는지 확인해요.
6. **설정 → 기능 → 클라우드 코드 실행 및 파일 생성** 이 켜져 있는지 확인해요("스킬 사용에 필요합니다").
7. "작년 계획서 올해로 바꿔 줘"처럼 시키면 스킬이 저절로 쓰여요.
- [캡처 필요] 실제 zip을 올린 뒤 목록에 나타난 화면 — 업로드는 금지라 이번에 찍지 않았어요.

## 4. inline AI ↔ 클로드 코워크 비교 (상위 호환인 이유)

| | inline AI | 클로드 코워크 |
|---|---|---|
| 폴더 초대(내 컴퓨터 파일 맡기기) | ✅ 작업 패널 → 접근 가능한 폴더 | ✅ 프로젝트 또는 폴더 → 폴더 추가 |
| 양식 주기(우리 학교 양식 그대로) | ✅ | ✅ |
| "목록 먼저, 아직 하지 마" | ✅ 편집 전 확인하기 | ✅ 수동 승인 |
| 늘 쓰는 규칙 저장 | 일반 설정 → inline AI 지시사항 | 설정 → 계정 → Claude 지침, 프로젝트 지침 + **스킬**(규칙 파일 묶음) |
