# 클로드(Claude) 데스크톱 앱 · 코워크 매뉴얼 (선생님용)

> 2026. 10. 5. 기준 · 이미지: `assets/shot/claude/` (`이름.png` 원본, `이름_1280.png` 강의용, 빨간 네모 = 누를 곳)
> **이번 캡처 때 강사 PC의 클로드 앱이 로그아웃 상태**였어요. 그래서 설치·로그인 화면만 찍었고, 로그인 뒤 화면은 모두 [캡처 필요]로 남겼어요. 메뉴 이름도 로그인 뒤 화면에서 직접 확인해야 해요(추측해서 적지 않음).

## 먼저 알아 둘 것 (공식 안내 기준)

- 클로드 다운로드 페이지: "Chat is available on all plans, including Free. **Claude Code and Claude Cowork are available on Pro, Max, Team, and Enterprise.**" → 코워크는 **유료(Pro 이상)** 가 필요해요.
- 2026. 9. 16. 공지 「Claude Cowork is now just Claude」: 코워크와 채팅이 **하나의 Claude 화면으로 합쳐짐**. Pro·Max부터 몇 주에 걸쳐 적용, Team·Free는 뒤이어 적용 예정. 기존 채팅·프로젝트·아티팩트·커넥터·스킬은 그대로 같은 자리에 있어요. (출처: https://claude.com/blog/cowork-is-now-claude)
  - 그래서 강의 때 화면에 '코워크'라는 이름이 따로 안 보일 수 있어요. "클로드에게 폴더를 맡기는 것 = 코워크"라고 설명하세요. [확인 필요: 강의 전날 강사 계정 화면]
- 요금(원화·달러 금액)은 [확인 필요] — claude.com/pricing 에서 강의 전날 확인.

## 1. 설치 3단계

**1-1. 내려받기** — `claude.ai/download` 에서 **Windows용 다운로드** 를 눌러요.
![](../assets/shot/claude/01_download_page_1280.png)
- 주의: 일반 PC는 'Windows용 다운로드', ARM 노트북(서피스 등)만 'Windows(arm64)'. Microsoft Store로도 받을 수 있어요.

**1-2. 설치 후 첫 화면** — 설치 파일을 실행하면 "Claude for Windows — Claude와 대화하는 가장 빠른 방법" 화면이 떠요. **시작하기** 를 눌러요.
![](../assets/shot/claude/02_welcome_1280.png)

**1-3. 로그인** — **Google로 계속하기** 또는 이메일 입력 → **이메일로 계속하기**.
![](../assets/shot/claude/03_login_1280.png)
- 주의: 코워크를 쓰려면 이 계정이 **Pro 이상 유료 요금제**여야 해요. 무료 계정은 채팅만 돼요.

> 앱 왼쪽 위 ≡ 메뉴(로그인 전에도 보임): 파일 · 편집 · 보기 · 이동 · 도움말
> - 보기: 명령 팔레트…(Ctrl+K) · 패널 닫기(Ctrl+\) · 분할 보기 · 실제 크기 · 확대 · 축소 · 새로고침(F5)
> - 이동: 뒤로 · 앞으로 · 이전 채팅(Ctrl+Shift+Tab) · 다음 채팅(Ctrl+Tab) · 검색…(Ctrl+Shift+K)

## 3. 공문서 하네스를 스킬로 올리기 [캡처 필요]

1. `materials/00_하네스_공문서/클로드_스킬용` 폴더를 확인해요. 안에 `SKILL.md` 와 `references/`(03~07 파일)가 있어요.
2. 이 폴더를 압축(zip)해요. — `SKILL.md`가 zip 안 맨 위(또는 폴더 하나 아래)에 오게.
3. 클로드 앱 **사용자 지정 → 스킬**(실제 이름 [확인 필요])에서 업로드해요.
4. 스킬 이름 `school-official-docs` 가 목록에 보이고 켜져 있는지 확인해요.
5. "작년 계획서 올해로 바꿔 줘"처럼 시키면 스킬이 저절로 쓰여요.
- 주의: 스킬 업로드 화면은 로그인 상태에서만 볼 수 있어 이번에 찍지 못했어요.

## 4. inline AI ↔ 클로드 코워크 비교 (상위 호환인 이유)

| | inline AI | 클로드 코워크 |
|---|---|---|
| 폴더 초대(내 컴퓨터 파일 맡기기) | ✅ 작업 패널 → 접근 가능한 폴더 | ✅ 프로젝트/폴더 선택 |
| 양식 주기(우리 학교 양식 그대로) | ✅ | ✅ |
| "목록 먼저, 아직 하지 마" | ✅ 편집 전 확인하기 | ✅ 권한 '수동' 쪽 [이름 확인 필요] |
| 늘 쓰는 규칙 저장 | 일반 설정 → inline AI 지시사항 | 설정의 지침 + **스킬**(규칙 파일 묶음) |
| 프로젝트(자료 묶음별 작업 공간) | ✖ | ✅ |
| 예약(정해진 시간에 자동으로) | ✖ | ✅ |
| 커넥터(드라이브·메일·캘린더 연결) | ✖ | ✅ |
| 한글(hwp) 문서 **직접** 편집 | ✅ 한/글 편집 모드가 편함 | △ 파일로 만들어 주지만 한글 창을 직접 고치진 않음 [확인 필요] |
| 비용 | Free 플랜 월 500크레딧(10/5 화면 기준) | **유료(Pro 이상)** 필요 |
| 설치 | Windows 앱 | 클로드 **데스크톱 앱** 필요(웹만으로는 폴더 작업 불가 [확인 필요]) |

한 줄 정리: "inline AI에서 배운 세 가지(일단 던지기·내 컴퓨터에 초대·양식 주기)는 그대로 쓰고, 클로드는 거기에 **프로젝트·스킬·예약·커넥터**가 더해져요. 다만 한글 직접 편집은 inline AI가 더 편해요."
