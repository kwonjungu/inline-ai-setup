## 강의 순서 (초안 — 게이트 1에서 확정)

0. 준비 — 설치·로그인·폴더 초대·'편집 전 확인' 켜기
1. 다운로드 폴더 정리
2. 학교 가정통신문 양식 맞추기 (오현교육통신 실제 양식)
3. 한글 표 만들기
4. 작년도 문서 업데이트 (2023 정보통신윤리교육 기본계획 → 2026)
5. 행정 처리 (예산표 오류·0원 맞추기·견적서→품의 산출내역)
6. 계획서로 기안문 (2025 오현 AI 과학의 날)
7. 계획서로 보고서 (디지털 동아리)
8. 계획서·통계로 PPT (+ 강의안 스타일 따라 만들기)
9. **마무리: 클로드 코워크** — inline AI로 한 일을 코워크로 하면? (상위 호환인 이유, 프로젝트·스킬·예약) + 클로드 데스크톱 앱 설치 3단계

## 팀 구성 (에이전트 역할)

| 역할 | 하는 일 | 입력 | 출력 |
|---|---|---|---|
| 총괄 (메인 세션) | 상태판 관리, 게이트에서 선생님과 문답, 커밋 | 모든 산출물 | `docs/STATUS.md` |
| ① 자료 구성 | 실습 파일 점검·보강, 정답 확인, 개인정보 검사 | `materials/` | 수정된 자료 + `docs/정답지.md` |
| ② 흐름 설계 | 시간 배분·실습 순서·전환 멘트 | 강의원칙, 자료 | `docs/강의흐름.md` |
| ③ 강의안 작성 | 슬라이드 원고 (7가지 슬라이드 유형만) | 흐름표, 디자인 가이드 | `deck/원고.md` → PPTX |
| ④ 프롬프트 삽입 | 실습 프롬프트를 슬라이드·사이트에 넣기, 초등 관점 다듬기 | 프롬프트.txt | 원고·사이트 반영 |
| ⑤ 자료 캡처·매뉴얼 | 실습 파일을 한글 자동화로 PDF→PNG 헤드리스 렌더, 전/후 비교 매뉴얼 | `materials/` | `site/manual/` |
| ⑥ 앱 캡처·매뉴얼 | inline AI 앱 화면 캡처(설치·로그인·폴더 초대·수락/거절·크레딧) | 실행 중인 앱 | `site/app-guide/` |
| ⑦ 검수 | 쉬운 말·사실(요금·기능)·개인정보·링크 점검 | 모든 산출물 | 검수 보고 → 해당 역할로 반려 |

## 루프 (한 바퀴)

```
[계획] → [생성: 담당 역할] → [검수: ⑦] → (반려 시 생성으로) → [게이트: 선생님 확인] → [커밋·푸시]
```

- 게이트 1: 강의 조건 확정 (시간·대상·형식·배포 방식) ← **지금**
- 게이트 2: 강의 흐름표 확정
- 게이트 3: 강의안 원고 확정 (디자인 전)
- 게이트 4: 슬라이드·사이트 최종 확인
- 캡처(⑤⑥)는 게이트 2 이후 병렬로 진행

## 단계별 일정

| 단계 | 병렬 가능 | 게이트 |
|---|---|---|
| 1. 자료 점검·정답지 (①) | ②와 병렬 | — |
| 2. 흐름 설계 (②) | | 게이트 2 |
| 3. 강의안 원고 (③+④) | ⑤⑥과 병렬 | 게이트 3 |
| 4. 캡처 매뉴얼 (⑤, ⑥) | | — |
| 5. 디자인·사이트 (③, F) | | 게이트 4 |
| 6. 최종 검수 (⑦) → 배포 | | — |

## 위험과 대응

| 위험 | 대응 |
|---|---|
| inline AI 앱은 데스크톱 앱이라 진짜 '헤드리스' 캡처가 어려움 | **검증 완료(10/5)**: 앱 실행 상태에서 pywinauto(UIA)로 버튼을 이름으로 눌러 조작 가능(마우스 이동 없음), PrintWindow로 창이 뒤에 있어도 캡처 가능. 접근성 트리는 첫 조회 후 약 2초 뒤 열림. 메시지 전송은 크레딧이 들므로 캡처 시나리오에서 최소화 |
| 앱 캡처에 대화 기록·계정명이 보임 | 선생님 확인(10/5): 기록이 찍혀도 됨 → 블러 처리 안 함 |
| 앱 UI가 자주 바뀜 | 캡처마다 날짜·버전 기록, 사이트에 "2026.10 기준" 표기 |
| 요금·크레딧·모델명이 자주 바뀜 | 공식 페이지 확인 후 [확인 필요] 표시, 강의 전날 재확인 |
| 공개 레포 개인정보 | 커밋 전 자동 검사(이름·전화·이메일·계좌), 실제 자료는 익명화본만 |
| 한글 렌더링 차이(빌더로 만든 hwpx) | 한글 자동화로 열어 PDF 저장되는지 ⑤가 확인 |
