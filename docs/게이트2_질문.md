> - Q2: **모든 실습을 실습 가능하게**, 구간마다 [필수 실습]/[여유 있으면] + 정답 결과물(`정답_예시/정답_…`) 띄우기

### Q1. inline AI 설치는 언제 하나요?
- **A (추천)** 연수 전에 사전 안내(설치·로그인까지)를 보내고, 당일 '0 준비'는 폴더 초대·설정만 10분
- B 당일 현장에서 설치부터 (준비 20분 → 08 PPT 실습을 시연으로 돌려야 함)
- C 사전 안내 + 당일 설치 안 된 분은 도우미가 따로 (도우미 인원 [확인 필요])

### Q2. 시연/실습 분류를 이대로 갈까요?
- **A (추천)** 06 기안문 = 실습, 07 보고서 = 시연(5분), 08 ⑤ 스타일 PPT = 미리 만든 결과로 비교 시연
- B 06 = 시연, 07 = 실습 (보고서가 더 쓸모 있다고 보시면. 단, 파일 4개 준비로 2~3분 더 듦)
- C 06·07 모두 실습, 대신 03 한글 표를 시연으로 (06·07을 각 8분으로 압축)

### Q3. 05 행정(엑셀) 실습을 전원이 할 수 있나요?
엑셀 작업은 MS 엑셀(한셀 불가) + GPT 계열 모델에서만 됩니다.
- **A (추천)** ①번 하나만 실습 + ⑥ 견적서 시연. MS 엑셀 없는 분은 짝과 함께 보기
- B 연수 장소 노트북에 MS 엑셀이 확실히 있으면 ①②까지 실습 (다른 구간에서 3분 빼야 함)
- C 05 전체를 시연으로 (엑셀 환경이 불확실할 때)

### Q4. 09 클로드 코워크 섹션 길이와 방식은?
- **A (추천)** 14분 = 설명 4분 + 라이브 시연 7분("스킬로 저장해 줘" → 한 줄로 재현) + 설치 안내 3분
- B 8분 = 슬라이드 설명 + 녹화 영상 (네트워크·유료 계정 시연 위험을 피함, 남는 6분은 08 실습에)
- C 20분 = 참가자 중 유료 계정 있는 분은 직접 설치·체험 (08을 시연으로)

### Q5. 실습 중 짝 활동을 넣을까요?
- **A (추천)** 기본은 혼자, "막히면 옆 분 화면 같이 보기"만 허용 (짝 지정 안 함)
- B 처음부터 2인 1조 짝 (한 사람은 치고, 한 사람은 결과 확인 — 구간마다 역할 바꾸기)
- C 짝 없이 전원 개인 실습 + 도우미 순회

### Q6. 쉬는 시간과 선택 실습 안내는?
- **A (추천)** 00:57에 5분 쉬는 시간(밀린 분 따라잡기), 선택 실습은 강의 사이트에 프롬프트 복사 버튼으로만 남김
- B 쉬는 시간 없이 115분 진행 + 마지막 질문 시간 12분
- C 쉬는 시간 대신 각 구간 끝에 "빨리 끝난 분은 ③④" 슬라이드를 띄워 개별 진행
