# 강의 흐름표 — inline AI로 내 업무 파일 맡겨 보기 (2시간 대면)

- 대상: 초등 담임 위주 교사. **당일 현장에서** 각자 노트북에 inline AI를 설치합니다.
- 원칙: ① 일단 던지세요 ② 내 컴퓨터에 초대하세요 ③ 정해진 양식을 주세요 + "긴 설명보다 자료 하나"
- 모든 실습의 리듬: **파일 열기 → 한 줄로 시키기 → 확인 → 필요한 부분만 다시**
- 프롬프트 번호 표기: `02-①` = `prompts/02_....txt`의 ①
- 상태: **게이트 2 답변 반영본** (2026-10-05). 결정 내용은 `docs/게이트2_질문.md` 맨 위 참조
- 정답 근거: `docs/정답지.md` (강사용). 정답 결과 파일은 `materials/<폴더>/정답_예시/`에 있음 — 아래 파일명은 **실제 파일명**(2026-10-05 제작)

> **시간 근거.** 프롬프트 하나에 "AI 응답 대기 1~2분 + 확인 1분"이 듭니다. 그래서 각 구간은 **[필수 실습] 1~2개**만 다 같이 하고, 나머지는 **[여유 있으면]** 으로 둡니다. 모든 프롬프트는 실습 가능하게 자료가 갖춰져 있으니, 빨리 끝난 분은 계속 진행하면 됩니다.
> 준비가 20분으로 늘어난 만큼(설치 포함) 각 실습 구간을 1~2분씩 줄였습니다. 쉬는 시간 5분은 그대로 둡니다. **시간이 밀리면 [여유 있으면] 안내를 생략하고 정답 띄우기로 바로 넘어갑니다.**

## 2. 구간 공통 진행 순서 (01~08)

모든 실습 구간은 같은 네 박자로 돌아갑니다. 참가자가 순서를 익히면 안내 시간이 줄어듭니다.

| 박자 | 시간 | 하는 일 |
|---|---|---|
| ① 자료 하나 | 30초 | 슬라이드 1장: 완성 결과 한 장 (전/후 또는 양식↔결과) |
| ② 필수 실습 | 구간의 60~70% | 프롬프트 사이트에서 복사 → 붙여 넣기 → 기다리는 동안 강사가 순회 |
| ③ 정답 띄우기 | 1~2분 | 강사 화면에 `정답_예시/정답_…` 파일을 열고 **함정 1~2개만** 짚기 (`docs/정답지.md` 기준). "내 결과와 나란히 놓고 보세요." |
| ④ 여유 있으면 | 30초 | 알약 슬라이드로 남은 프롬프트 번호만 보여 주고 다음으로. 빨리 끝난 분은 계속, 나머지는 사이트에서 나중에 |

- 정답을 띄우는 시점: **필수 실습 마감 1~2분 전**. 결과가 안 나온 분도 정답을 보며 "무엇이 나와야 하는지"는 가져가게 합니다.
- 결과가 늦게 나오면 정답 파일을 먼저 띄우고, 참가자 결과는 쉬는 시간이나 다음 구간 대기 시간에 확인합니다.

## 4. 구간별 상세

### 00:00–00:05 여는 말 (5분, 설명)
- **여는 멘트:** "오늘은 AI를 공부하는 시간이 아니에요. 선생님 컴퓨터에 있는 진짜 업무 파일을 AI에게 맡겨 보는 시간입니다. 두 시간 뒤에는 가정통신문, 기안문, 발표 자료가 하나씩 손에 남아요."
- **자료 하나:** 정리 안 된 다운로드 폴더 화면 한 장 (`01/다운로드_흉내`). "선생님 다운로드 폴더도 이렇죠?"
- **원칙 세 가지:** 알약 슬라이드 한 장, 각 한 문장.
- **전환 멘트:** "말로 듣는 것보다 해 보는 게 빨라요. 설치부터 같이 할게요. 설치 파일 받는 동안 제 화면을 봐 주세요."

### 00:25–00:33 01 다운로드 정리 (8분)
- **여는 멘트:** "다운로드 폴더 정리는 다들 미뤄 두시죠. 폴더째 AI에게 넘겨 볼게요. 파일은 안 열어도 돼요."
- **자료 하나:** 정리 전 폴더(30개 뒤섞인 파일) → 정리 후 폴더(01_공문~99_확인필요) 전/후 캡처 한 장.
- **[필수 실습]** `01-①` 개수만 세기 → `01-②` 표 먼저 보여 주고, 좋다고 하면 옮기기
