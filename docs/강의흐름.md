# 강의 흐름표 — inline AI로 내 업무 파일 맡겨 보기 (2시간 대면)

- 대상: 초등 담임 위주 교사, 각자 노트북에 inline AI 설치
- 원칙: ① 일단 던지세요 ② 내 컴퓨터에 초대하세요 ③ 정해진 양식을 주세요 + "긴 설명보다 자료 하나"
- 모든 실습의 리듬: **파일 열기 → 한 줄로 시키기 → 확인 → 필요한 부분만 다시**
- 프롬프트 번호 표기: `02-①` = `materials/02_.../프롬프트.txt`의 ①
- 상태: 게이트 2 검토용 초안 (확정 전). 결정이 필요한 곳은 `docs/게이트2_질문.md` 참조

## 2. 실습 / 시연만 / 선택 분류

| 구간 | 필수 실습 (다 같이) | 강사 시연만 | 선택 실습 (빨리 끝난 분·집에서) |
|---|---|---|---|
| 01 | ① 개수 세기, ② 표 먼저 → 옮기기 | ③ 중복 파일 묶기 | ④ 내 진짜 다운로드 폴더 |
| 02 | ① 양식 맞춰 새 통신문, ② 날짜·요일 확인 | — | ③ 문자 200자, ④ 알림장 3줄 |
| 03 | ① 업무분장 표 | ③ 명렬표 → 미제출 표 | ②, ④ |
| 04 | ① 바꿀 곳 목록만, ② 새 이름 저장 | ③ 작년/올해 비교표 | ④ 학부모 문자 |
| 05 | ① 예산표 오류 찾기 + 계산식 | ⑥ 견적서 → 산출 내역 + 한글 금액 | ②, ③, ④, ⑤ |
| 06 | ② 날짜 함정 먼저, ① 기안문 | — | ③ 에듀파인용 글, ④ 통신문 |
| 07 | — | ① 양식 채우기, ③ 숫자 검산표 | ①~③ 전체 |
| 08 | ① 우리 학교 양식 PPT | ⑤ 강의안 스타일 PPT, ⑥ 비교 | ②, ③, ④ |
| 09 | — | 스킬로 저장해 줘 / 설치 화면 | 데스크톱 앱 설치 |

### 줄이거나 시연으로 돌린 이유

1. **07 보고서 → 시연만 (5분).** 06 기안문과 원리가 같습니다(계획서 + 우리 양식 → 문서). 07은 파일 4개를 열고 첨부해야 해서 준비만 2~3분이 걸리고, 표에 10회차 줄 추가까지 들어가 대기 시간이 깁니다. 06에서 직접 해 본 뒤라 "같은 방법을 자료 세 개로 하면 이렇게 된다"를 보여 주는 것으로 충분합니다. 단, ③ '숫자 검산표'는 "AI 결과를 AI에게 검산시키기"라는 꼭 필요한 습관이라 시연에서 반드시 보여 줍니다.
2. **05 행정 → 실습 1개 + 시연 1개.** 엑셀 작업은 MS 엑셀(한셀 불가) + GPT 계열 모델에서만 됩니다(`00_먼저읽기.txt`). 학교 노트북에 MS 엑셀이 없는 분이 있을 수 있어 전원 실습이 어렵습니다. 가장 짧고 효과가 바로 보이는 ①(틀린 금액 찾기)만 실습, 실제 오현초 견적서 ⑥은 시연합니다. ②④(예산 맞추기·0원 맞추기)는 시간이 오래 걸리고 결과 검토가 길어 선택으로 돌립니다.
3. **03 한글 표 → 8분, ①만 필수.** 효과가 바로 보이고 쉬워서 짧게 성공 경험을 주는 구간입니다. ③(엑셀 첨부)은 02·04에서 이미 첨부를 해 본 뒤라 시연으로 충분합니다.
4. **08 ⑤ 스타일 따라 만들기 → 시연(미리 만든 결과 비교).** PPT 10장 생성은 대기 시간이 길고 글꼴(Black Han Sans·Pretendard) 설치 여부에 따라 결과가 달라집니다. 강사가 ①결과와 ⑤결과를 **미리 만들어 두고 나란히 보여 주는 것**이 "자료 하나가 더 강력한 예시"를 가장 잘 보여 줍니다. ("지금 보고 계신 이 강의안도 같은 방법으로 만들었어요.")
5. **각 구간의 ③④(문자·알림장·에듀파인 글)는 선택.** 같은 결과를 다른 모양으로 바꾸는 활동이라 한 번만 보면 원리를 압니다. 사이트에 프롬프트 복사 버튼으로 남겨 둡니다.

## 3. 구간별 상세

### 00:00–00:05 여는 말 (5분, 설명)
- **여는 멘트:** "오늘은 AI를 공부하는 시간이 아니에요. 선생님 컴퓨터에 있는 진짜 업무 파일을 AI에게 맡겨 보는 시간입니다. 두 시간 뒤에는 가정통신문, 기안문, 발표 자료가 하나씩 손에 남아요."
- **자료 하나:** 정리 안 된 다운로드 폴더 화면 캡처 한 장 (`01/다운로드_흉내` 폴더 화면). "선생님 다운로드 폴더도 이렇죠?"
- **원칙 3개 소개:** 알약 슬라이드로 한 번에. 설명은 각 한 문장.
- **전환 멘트:** "말로 듣는 것보다 한 번 해 보는 게 빨라요. 바로 준비부터 할게요."

### 00:05–00:15 0 준비 (10분, 실습)
- **여는 멘트:** "AI를 내 컴퓨터에 초대하는 단계예요. 폴더 하나만 열어 주면 됩니다."
- **자료 하나:** inline AI 오른쪽 위 '접근 가능한 폴더' 화면 캡처 (⑥ 앱 캡처 담당이 제작).
- **할 일 (`00_먼저읽기.txt` 1~5):** 실행·로그인 → 바탕화면 `inlineAI_실습` 폴더 추가 → '편집 전 확인하기' 켜기 → 모델 GPT-5.4(무료) 선택 [확인 필요: 강의 당일 모델명·무료 여부] → "실습이 바뀌면 새 채팅".
- **막히면:** "로그인이 안 되면 옆 분 화면으로 같이 보셔도 돼요. 폴더 추가가 안 보이면 오른쪽 위를 다시 봐 주세요." / 설치 안 된 분은 도우미가 따로 [게이트2-Q1].
- **전환 멘트:** "자, 이제 첫 일을 맡겨 볼게요. 파일을 하나도 안 열어도 되는 일부터요."

### 00:15–00:25 01 다운로드 정리 (10분, 실습)
- **여는 멘트:** "다운로드 폴더 정리는 다들 미뤄 두시죠. 폴더째 AI에게 넘겨 볼게요. 파일은 안 열어도 돼요."
- **자료 하나:** 정리 전 폴더(30개 뒤섞인 파일) → 정리 후 폴더(01_공문~99_확인필요) 전/후 캡처 한 장.
- **칠 프롬프트:** `01-①`(개수만 세기) → `01-②`(표 먼저 보여 주고, 좋다고 하면 옮기기)
- **강조:** ②의 "옮기기 전에 표를 먼저 보여 줘" = 오늘 내내 쓸 안전장치.

- **막히면:** "'접근 가능한 폴더'에 다운로드_흉내가 들어가 있는지 봐 주세요." / "표만 나오고 안 옮겨졌다면 정상이에요. '좋아, 옮겨 줘'라고 한 번 더 말해 주세요."
- **전환 멘트:** "폴더는 됐고, 이제 파일 안으로 들어가 볼게요. 우리 학교 가정통신문이요."

### 00:25–00:37 02 가정통신문 양식 맞추기 (12분, 실습)
- **여는 멘트:** "AI에게 '가정통신문 써 줘' 하면 처음 보는 모양이 나와요. 우리 학교 양식을 주면 우리 학교 통신문이 나옵니다."

### 01:02–01:12 05 행정 처리 (10분, 실습 1 + 시연 1)
- **여는 멘트:** "예산표 금액 틀린 거, 눈으로 찾으면 한참 걸려요. AI에게 찾게 하고 계산식으로 바꾸게 해요."
