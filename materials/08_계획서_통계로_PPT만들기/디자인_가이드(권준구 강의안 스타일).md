# 디자인 가이드 — 「말로 만드는 수업 자료」 강의안 스타일

참고 파일: 스타일참고_강의안_말로만드는수업자료(발췌14장).pdf
참고 사이트: https://classroomaicontents.vercel.app/

## 1. 판형
- 16:9 가로 (960 × 540)
- 여백 넉넉하게, 왼쪽 정렬 위주
- 이모지 쓰지 않기 (표지 부제에 1개 정도만 허용)

## 2. 글꼴
- 제목: Black Han Sans (굵고 큰 한글 제목, 자간 넓게)
- 본문·부제·카드: Pretendard (Regular / SemiBold / Bold)
- 크기: 표지 제목 56pt · 슬라이드 제목 28~41pt · 부제 18~22pt · 카드 글 12~16pt

## 3. 색
| 용도 | 색 |
|---|---|
| 기본 글자 | #111111 |
| 부제·설명 | #707072 |
| 쪽 번호·꼬리말 | #9E9EA0 |
| 카드 배경 | #F2F2F2 |
| 표지·섹션 표지 배경 | #111111 (글자 흰색) |
| 포인트(섹션마다 1색) | #ED1AA0(핑크) · 빨강 · 청록 중 하나 |

## 4. 슬라이드 유형 (이 7가지만 반복)
1. 표지: 검정 배경, 작은 알약 라벨("교원 연수 · ○○"), 큰 흰 제목 두 줄, 부제 한 줄, 아래 왼쪽 이름
2. 섹션 표지: 검정 배경, 섹션 제목 + 설명 두 줄, 오른쪽 아래에 아주 큰 회색 번호(01, 02…)
3. 한 문장 슬라이드: 흰 배경, 위에 짧은 가로 막대, 큰 제목 두 줄("~가 아니라 / ~입니다."), 아래 회색 한 줄
4. 제목 + 부제 + 카드 3개: 회색 둥근 카드, 카드 위에 검정(또는 포인트색) 알약 태그, 아래 설명 한 줄
5. 단계 1-2-3: 가로 3칸, 각 칸 위 가는 선, 동그란 번호(포인트색), 굵은 단계명 + 회색 설명
6. 알약 버튼 모음: 둥근 테두리 알약에 "① 목표 — …" 형식으로 짧게
7. 미션: 작은 포인트색 라벨("실습 미션") + 제목 + 점 목록 3개 + 오른쪽 예시 이미지

## 5. 공통 규칙
- 꼬리말: 오른쪽 아래 "섹션 이름  쪽번호" (회색, 작게)
- 한 슬라이드 = 한 메시지. 한 장 글자 100자 안팎(최대 140자), 제목 줄당 20자, 카드 3~4개·각 20자
- 설명은 발표자 노트로
- 문장은 "~해요/~합니다" 대화체, 짧게
- 마지막 장: 한 문장 정리 슬라이드 + 다시 볼 사이트 주소
