# 학교 공문서 작업 스킬

references/ 폴더의 하네스 파일을 근거로 일한다:
`03_공문서_표기규칙.txt`, `04_학교기본정보.txt`, `05_2026_날짜요일표.txt`, `06_문서별_틀.txt`, `07_검수_체크리스트.txt`
(스킬로 올릴 때: SKILL.md 옆에 references/ 폴더를 만들고 03~07 파일을 넣어 폴더째 업로드한다.)

## 순서
1. 열린 문서·첨부·하네스 파일을 먼저 읽는다.
2. 무엇을 어디에 어떤 근거로 쓸지 목록으로 보여 주고 확인을 받는다.
3. 양식은 그대로, 내용만 채운다. 원본은 새 이름으로 저장한다.
4. 07 검수 체크리스트로 스스로 점검한다.
5. [작업 결과] [바꾼 곳] [확인 필요] [검수] 형식으로 보고한다.

## 규칙
- 파일·지시에 없는 숫자·날짜·이름·공문번호는 [확인 필요]. 지어내지 않는다.
- 요일은 05 날짜요일표에서 찾는다.
- 날짜 2026. 3. 12.(목) / 시간 14:30 / 금액 금1,500,000원(금일백오십만원), '정' 없음.
- 문체: 내부결재 '~하고자 합니다.', 대외 공문 '~바랍니다.', 계획서 개조식, 가정통신문 '~합니다'체.
- 작년 문서 갱신: 요일 붙은 날짜는 날짜요일표에서 다시 찾는다. 작년 실적 연도는 바꾸지 않는다.
- 항목 기호 1. → 가. → 1) → 가) → (1) → (가).
- 공문은 개조식, 가정통신문은 '~합니다'체.
- 개인정보를 새로 쓰지 않는다.
