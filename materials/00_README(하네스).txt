[README] 하네스 — 먼저 읽어 주세요

하네스(harness)란?
  말에게 씌우는 '마구'처럼, AI가 엉뚱한 데로 가지 않게 채워 두는 '업무 지침' 묶음이에요.
  이 실습 폴더에서는 00_업무지침 폴더가 하네스입니다. AI가 일하기 전에 먼저 읽어요.

  00_업무지침/01_기본지침_짧은판.txt   → inline AI 설정 > 일반 설정 > inline AI 지시사항에 한 번 붙여 넣기
  00_업무지침/02~07                    → 표기 규칙 · 학교 정보 · 2026 날짜표 · 문서 틀 · 점검 목록
  00_업무지침/클로드_스킬용             → 같은 규칙을 클로드 '스킬'로 올릴 때 (09 코워크)
  쓰는 법은 한 줄: "00_업무지침 폴더의 규칙을 따라서 …"

준비 (한 번만)
  1. inline AI 설치(https://inline-ai.com) → 로그인
     초대 이벤트(무료 1,000 크레딧): https://portal.inline-ai.com/invitation-promotion?code=K2YERY3H (코드 K2YERY3H)
  2. 접근 가능한 폴더 → 바탕화면 'inlineAI_실습' 하나만 추가 (하네스도 함께 들어가요)
  3. 승인 모드는 '모든 편집 허용하기' 그대로
  4. 01_기본지침_짧은판 내용을 지시사항에 붙여 넣기
  5. 실습이 바뀌면 '새 에이전트', 한글 파일은 작업할 것 하나만 열기

실습은 폴더마다 ★ 필수 프롬프트 하나만 하면 돼요
  01 다운로드 정리      다운로드_흉내 폴더 첨부 → 규칙대로 정리(표 먼저)
  02 가정통신문         양식 열기 + 메모 첨부 → 양식 그대로 새 통신문
  03 한글 표            표로_만들_자료 열기 → 업무분장 표, 마감 빠른 순
  04 작년 문서          작년 신청서 열기 + 메모 첨부 → 2026년판 새로 저장
  05 행정 처리          체험학습_예산표(MS 엑셀) → 틀린 금액 찾고 계산식으로
  06 기안문             운영계획 열기 + 기안문 예시 첨부 → 예시 형식 그대로
  07 보고서             보고서 양식 열기 + 자료 3개 첨부 → 근거로만 채우기
  08 PPT               PPT 양식 열기 + 자료 3개 첨부 → 8장 이내 발표 자료
  나머지 '더 해보기'는 시간 남을 때만. 정답은 각 폴더의 정답_예시에 있어요.

프롬프트는 강의 사이트 '프롬프트 모음'에서 [복사]
  https://inline-ai-setup.vercel.app/prompts.html
  (인터넷이 안 될 때만 00_프롬프트_전체.txt)
